# 다올로직스 데스크톱 앱 (Windows)

다올로직스 통합 관리 시스템 화면을 여는 **Electron 셸**입니다.

## 여기에 없는 것

**업무 로직도 데이터도 들어 있지 않습니다.** 이 앱이 하는 일은 네 가지뿐입니다.

1. 정해진 주소의 화면을 전용 창으로 연다
2. 로그인 상태를 기억한다
3. 연결이 안 되면 그렇다고 말한다 (흰 화면 대신)
4. 바깥 링크는 기본 브라우저로 보낸다

정산 로직·요율·데이터는 전부 서버에 있고, 접근하려면 로그인해야 합니다.
그래서 이 저장소는 공개해도 됩니다 — 그리고 **공개여야 합니다.**
앱이 자동 업데이트를 확인할 때 토큰 없이 릴리스를 읽어야 하기 때문입니다.
비공개로 두면 토큰을 앱 안에 넣어야 하고, 설치본을 가진 사람이 그 토큰을 꺼낼 수 있습니다.

## 받기

[Releases](../../releases) 에서 `DaolLogics-Setup-*.exe` 를 받아 실행하세요.

처음 실행할 때 Windows SmartScreen 이 「알 수 없는 게시자」 경고를 냅니다 —
「추가 정보」 → 「실행」. 코드 서명 인증서가 없어서 그렇습니다.

## 새 버전 내보내기

1. `package.json` 의 `version` 을 올립니다 (**이걸 잊으면 업데이트가 안 걸립니다**)
2. Actions → 「릴리스 (Windows)」 → Run workflow

`electron-builder` 가 릴리스를 만들고 `.exe` 와 `latest.yml` 을 같이 올립니다.
`latest.yml` 이 자동 업데이트의 기준 파일이라, 손으로 `.exe` 만 올리면 소용없습니다.

설치된 앱은 켠 뒤 8초쯤 지나서, 그리고 12시간마다 확인합니다.
받아두기만 하고 **설치는 앱을 끌 때** 합니다 (정산 작업 도중에 창이 닫히면 안 되니까요).
「도움말 → 업데이트 확인」 으로 직접 확인할 수도 있습니다.

## 접속 주소

`app-config.json` 의 `appUrl` 을 읽습니다. **기본값은 없습니다** — 값이 없으면
에러 화면을 띄우고 멈춥니다. 기본값을 두면 주소가 바뀐 뒤에도 옛 사이트를 조용히
계속 열게 되는데, 그게 「되는 것처럼 보이는데 안 되는」 제일 나쁜 상태입니다.

우선순위:

1. 환경변수 `DAOL_APP_URL` (임시 확인용)
2. `%APPDATA%\다올로직스\app-config.json` (설치 후 관리자가 바꿔 넣는 자리 — **재설치 불필요**)
3. 설치본에 들어 있는 `app-config.json`

지금 무엇을 보고 있는지는 「도움말 → 이 앱에 대하여」에 주소와 출처가 같이 나옵니다.

## 개발

```bash
npm install
DAOL_APP_URL=http://localhost:3000 npm start   # Windows: set DAOL_APP_URL=...
```

개발 모드(`app.isPackaged === false`)에서는 자동 업데이트를 확인하지 않습니다.
